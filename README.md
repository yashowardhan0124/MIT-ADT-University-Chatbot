# 🎓 MIT-ADT University Chatbot

An AI-powered university chatbot designed to provide students with quick and interactive access to university-related information through a modern and responsive web interface.

## ✨ Features

- 🤖 AI-powered chatbot interface
- 🔐 User Login and Signup
- 💬 Interactive chat dashboard
- 📊 Student dataset upload using CSV
- 🗄️ SQLite database integration
- 🎨 Professional MIT-ADT themed UI
- 📱 Responsive web design
- ⚡ Flask-based backend

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Pandas
- Jinja2
- Git & GitHub

📌 Main Modules
🔐 Login & Signup

Allows users to register and access the chatbot platform through an authentication system.

🤖 Chatbot Dashboard

Provides an interactive interface where users can enter questions and receive university-related information.

📂 Dataset Upload

Provides an interface for uploading CSV datasets for student-related data processing.

🗄️ Database

Uses SQLite for storing and managing application data.

🔒 Security & Privacy

The following files are excluded from the GitHub repository:

.venv/
Generated Flask session files
.env configuration files
Student CSV datasets
Local SQLite database

Sensitive or personal student information should not be uploaded to a public repository.
